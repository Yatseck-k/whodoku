## О проекте

**Whodoku** — Composer-пакет детективной игры. Расставьте гостей по комнатам с учётом показаний. В каждой строке и в каждом столбце может стоять максимум один гость. В оставшейся пустой клетке находится улика, по которой можно определить виновного.

В репозитории есть Laravel-приложение `dev-app` для локального запуска игры и проверки пакета без SelfBio.

| **Администрирование** | Подключаемый провайдер Orchid для игровых экранов, прав доступа и редактора карты |

## Быстрый старт

Нужны Git, Docker с Compose и Make.

```bash
git clone https://github.com/Yatseck-k/whodoku.git
cd whodoku
make setup
```

Откройте [игру](http://localhost:8088/game), [каталог дел](http://localhost:8088/puzzles) или [правила](http://localhost:8088/rules). Команда устанавливает зависимости, собирает и публикует ассеты, применяет миграции, заполняет справочники и при необходимости создаёт гостевое дело. Данные PostgreSQL сохраняются после `make down` и повторного запуска `make setup`.

Локальное приложение использует ключ разработки, локальную базу и тестовый вход игрока. Используйте его только для разработки. Чтобы запустить контейнеры от другого пользователя, задайте `WHODOKU_UID` и `WHODOKU_GID`.

## Команды разработки

| Команда | Назначение |
| --- | --- |
| `make up` / `make down` | Запустить или остановить сервисы разработки |
| `make build` | Пересобрать и опубликовать ассеты в локальном приложении |
| `make test` | Запустить модульные и интеграционные тесты PHPUnit после `make setup` |
| `make frontend-test` | Запустить Vitest, проверку типов Vue и ESLint |

Интеграционные тесты используют локальную базу и проверяют, в частности, загрузку игры, каталога и страницы дела.

## Подключение к Laravel

- Провайдер пакета регистрирует игровые маршруты, миграции и настройки `killdoku` и `story`. Приложение предоставляет подключение к базе `whodoku` и guard `player`. Пример есть в [настройках локального приложения](dev-app/config).
- По умолчанию Inertia использует шаблон `whodoku::whodoku`. Чтобы подключить свой шаблон, например для SEO-разметки, задайте `whodoku.root_view`.
- Сборка создаёт `public/build/whodoku` с отдельным Vite manifest для игры и редактора карты. Чтобы опубликовать ассеты из собранного пакета в приложении, выполните `php artisan vendor:publish --tag=whodoku-assets --force`. Команда перезапишет совпадающие файлы в публичном каталоге.
- Для подключения Orchid зарегистрируйте `Whodoku\Orchid\PlatformProvider`. Он добавляет маршруты в приватную группу Orchid, игровое меню и права `platform.puzzles.*`. Подключайте маршруты только через провайдер, чтобы избежать дублирования. Некоторые действия админки ожидают `Whodoku\Models\User` и пользователей в игровой схеме.

Интеграцию с другими Laravel-приложениями ещё предстоит проверить, включая подключение к базе, guard игрока, Telegram, оплату, SEO и Orchid. Оставшиеся этапы описаны в [плане интеграции](WORK/WHODOKU_PACKAGE_PLAN.md).
